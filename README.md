# بنك المبادرات — الموقع الجديد ولوحة التحكم

موقع جديد لـ **بنك المبادرات** (مبادرة من المنتدى الاجتماعي التنموي)، بهوية البنك (البرتقالي `#F27731`، الأزرق `#05629F`، الأصفر `#F2B12F`) وبأسلوب قريب من موقع المنتدى [sdf-pal.org](https://sdf-pal.org): خلفيات داكنة، وكولاج صور، وصف أرقام بأيقونات برتقالية، وأقسام كريمية، وبطاقات دائرية الحواف، وخط Rubik.

كل المحتوى مسحوب من [initiativesbank.ps](https://initiativesbank.ps):

| المحتوى | العدد |
|---|---|
| مبادرات (بكل أقسامها: ما هي، لماذا، الأهداف، الأنشطة، السياق، الاقتباسات، المعارض، الفرق) | 22 |
| أخبار وإعلانات (نص كامل) | 9 |
| شهادات «ماذا يقول المبادرون» | 9 |
| صور (محفوظة محليًا في `assets/uploads`) | 169 |
| صفحات: من نحن، الشركاء، ادعم البنك، تواصل، قدّم فكرتك، الخصوصية، الشروط | ✓ |

## هيكل المشروع

```
index.html, initiatives.html, initiative.html, news.html, post.html,
ideas.html, about.html, partners.html, support.html, contact.html,
submit.html, privacy.html, terms.html, 404.html   ← صفحات الموقع
admin/                 ← لوحة التحكم
data/site-data.js      ← كل بيانات الموقع (تقرأها الصفحات واللوحة)
data/site-data.json    ← نسخة JSON من نفس البيانات
assets/css, assets/js  ← التصميم والسكربتات
assets/uploads/        ← الصور
tools/                 ← سكربتات سحب البيانات من الموقع القديم
```

موقع ثابت بالكامل بلا خادم ولا خطوة بناء: يعمل على GitHub Pages، أو بفتح `index.html` مباشرة.

## ما الجديد في التنظيم

- **مكتبة مبادرات بفلاتر:** بحث، والمحافظة، والمجال، والفئة المستهدفة، والمسار/المشروع، والسنة، مع ترتيب وعرض شبكة/قائمة. الفلاتر تُحفظ في الرابط فيمكن مشاركتها.
- **صفحة مبادرة منظّمة:** بطاقة معلومات جانبية، وفهرس للأقسام، ومعرض صور بعرض مكبّر، وفريق المبادرة، ومبادرات ذات صلة، وأزرار مشاركة.
- **تصنيف جديد** لكل مبادرة: المحافظة، والمجالات، ومجموعات الفئات، والمسار (مثل «الوصول للجميع – MAP» و«SDF Youth Hub»). استُخرج التصنيف آليًا من النصوص ويمكن تصحيحه من اللوحة.
- **نموذج «قدّم فكرتك»** بنفس حقول الموقع الأصلي، والنموذج الخاص بذوي الإعاقة، وحفظ تلقائي للمسودة.
- **بنك الأفكار:** صفحة عامة تُغذّى من اللوحة.

## لوحة التحكم (`/admin`)

- **نظرة عامة:** مؤشرات، ومخطط المبادرات شهريًا، وتوزيع حسب المحافظة والمسار والمجال والفئة، وقائمة «جودة البيانات» (مبادرات بلا صور أو فريق أو عدد مستفيدين…).
- **المبادرات:** جدول بفلاتر، وتمييز، ونسخ، وحذف، ومحرّر كامل بكتل المحتوى (قسم نصي، اقتباس، بطاقات معلومات، معرض صور، فريق، خاتمة)، مع رفع الصور وترتيبها.
- **الأخبار والإعلانات:** محرّر HTML مع معاينة مباشرة.
- **الطلبات:** طلبات «قدّم فكرتك»، مع تغيير الحالة، والملاحظات، والتحويل إلى مبادرة أو فكرة، وتصدير CSV.
- **محتوى الموقع:** الهوية، والأرقام، والقيم، ومن نحن، والشركاء، والشهادات، والتواصل، والنموذج، والصفحات القانونية.
- **مكتبة الوسائط** و**النشر**.

### كيف تعمل التعديلات

1. كل تعديل يُحفظ **مسودةً** في متصفحك.
2. زر **معاينة** يفتح الموقع بالمسودة (يظهر شريط أصفر «وضع المعاينة»).
3. **النشر:** أدخل رمز GitHub من نوع *Fine-grained token* بصلاحية `Contents: Read & Write` على هذا المستودع فقط، فتحدّث اللوحة `data/site-data.js` مباشرة، وتُرفع الصور الجديدة إلى `assets/uploads/dashboard/`. كبديل، نزّل `site-data.js` من صفحة النشر وضعه في `data/`.

> **ملاحظة أمان:** اللوحة صفحة ثابتة، فمن يفتحها يرى البيانات العامة نفسها الموجودة في الموقع. الحماية الفعلية هي رمز GitHub: بدونه لا يمكن تغيير الموقع المنشور.

### طلبات التقديم والخصوصية

تحتوي الطلبات أسماء أعضاء الفرق وهواتفهم وبريدهم، لذلك **لا تُحفظ أبدًا داخل `site-data.js`** المنشور. لاستقبال الطلبات من كل الزوار:

- ضع رابط استقبال (مثل Formspree أو Google Apps Script) في **محتوى الموقع ← نموذج التقديم ← رابط استقبال النماذج**، ثم صدّر الطلبات من تلك الخدمة بصيغة JSON واستوردها في صفحة **الطلبات**.
- بدون رابط، يُحفظ الطلب في متصفح المتقدّم ويُعرض عليه إرسال نسخة بالبريد إلى `info@initiativesbank.ps`.

## التشغيل محليًا

```bash
python3 -m http.server 8000
# الموقع:  http://localhost:8000
# اللوحة:  http://localhost:8000/admin/
```

## النشر على GitHub Pages

من إعدادات المستودع: **Settings ← Pages ← Deploy from a branch**، ثم اختر الفرع `main` والمجلد `/ (root)`.

## إعادة سحب البيانات من الموقع القديم

```bash
tools/fetch.sh /tmp/ib-work   # يحتاج python3 مع beautifulsoup4 و lxml
```

ينزّل محتوى WordPress عبر REST API وصفحات المبادرات، ويعيد توليد `data/site-data.js`، ويحمّل الصور الناقصة.
**تنبيه:** يستبدل هذا السكربت أي تعديلات أُجريت من اللوحة.
